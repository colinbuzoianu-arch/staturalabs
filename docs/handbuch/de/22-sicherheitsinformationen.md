# Sicherheitsinformationen

## Wozu

Nach einem Beinaheunfall, bei einer neuen Regel, nach einer Änderung an
einer Anlage muss eine Information **alle Betroffenen** erreichen — und es
muss belegbar sein, dass sie angekommen ist. Genau das ist der Zweck dieses
Moduls: nicht das Versenden, sondern der **Nachweis**.

## Eine Information verfassen

Unter **Sicherheitsinformationen › Neu**:

1. **Titel** und **Text**. Einfache Formatierung ist möglich; der Text wird
   vor dem Speichern bereinigt, damit kein eingebetteter Code gespeichert
   wird.
2. **Dringlichkeit** — *Information* oder **Sicherheitswarnung**. Eine
   Sicherheitswarnung erscheint zusätzlich als Band über jeder Seite.
3. **Bereich** — Arbeitnehmerschutz, Umwelt oder allgemein.
4. **Verknüpfung** (höchstens eine): ein Dokument, ein Ereignis, eine
   Betriebsanweisung oder eine Maßnahme. Verlinkt wird der Gegenstand —
   Personen- oder Gesundheitsdaten aus einem Ereignis werden **nicht** in
   den Text übernommen.
5. **Empfängerkreis** — Unternehmen, Standort, Organisationseinheit (mit
   Untereinheiten), Arbeitsplatz (die dort zugeordneten Personen) oder
   Rolle.
6. **Bestätigung erforderlich** und eine **Frist**.

Solange sie Entwurf ist, lässt sich alles ändern.

## Veröffentlichen

Beim Veröffentlichen hält die Anwendung den Empfängerkreis als **Liste
fest** — eine Momentaufnahme. Das ist bewusst so: wer nächste Woche
dazukommt, ist nicht rückwirkend jemand, der nicht bestätigt hat. Für
Neuzugänge gibt es die Schaltfläche **Empfänger aktualisieren**.

Jeder Empfänger mit Konto erhält eine Benachrichtigung (und, sofern
konfiguriert, eine E-Mail) mit einem Link auf die Information. An
Zugangscode-Konten ohne echte E-Mail-Adresse wird nie gemailt.

**Zurückgenommen wird nichts.** Was mitgeteilt wurde, bleibt als
Mitteilung bestehen; eine falsche Information wird **archiviert** und durch
eine neue ersetzt. Eine archivierte Information bleibt mit ihrer
Bestätigungsliste lesbar.

## Kenntnisnahme

Empfänger öffnen die Information unter **Meine Sicherheitsinformationen**
und bestätigen mit einem Klick „gelesen und verstanden". Die Bestätigung
wird einmal gestempelt und nie zurückgenommen — sie ist eine Aussage, kein
Schalter. **Gelesen** und **bestätigt** sind zwei verschiedene Angaben.

Beschäftigte **ohne E-Mail-Adresse** bekommen bei einer bestätigungs-
pflichtigen Sicherheitswarnung eine **Sperrkarte** vor die angeforderte
Seite: erst lesen und bestätigen, dann weiterarbeiten. Die Information selbst
bleibt dabei immer erreichbar.

## Erinnerungen

Vor Ablauf der Frist und einmal danach erinnert die Anwendung die
**noch nicht** Bestätigten — je Stufe genau einmal. Eine Führungskraft kann
zusätzlich gezielt die eigenen offenen Fälle anstoßen.

## Status — drei Sichten auf dieselbe Wahrheit

- **Administration / EHS**: jede angesprochene Person mit Zustand.
- **Führungskraft**: ausschließlich die eigenen Organisationseinheiten —
  das ist der *Team-Status*.
- **Betriebsrat**: nur **Summen**, keine Namensliste; kleine Gruppen werden
  wie überall unterdrückt.

Der CSV-Export folgt genau dieser Sicht. Die Datei kann niemals mehr
enthalten als der Bildschirm.

## Aushang

Für das Anschlagbrett erzeugt die Anwendung einen **Aushang** als A4-PDF:
Titel, Datum, Standort, die Mitteilung, die **Funktion** der absendenden
Person — niemals persönliche Angaben — und ein Feld für die Kenntnisnahme.
Eine Empfängerliste steht absichtlich **nicht** darauf: ein Anschlagbrett
ist öffentlich, die Bestätigungsliste ist interner Nachweis.

## Aufbewahrung

Für den Nachweis, dass eine Information weitergegeben wurde, gibt es im
deutschsprachigen Raum **keine gesetzliche Frist**. Die Anwendung setzt
daher eine betriebliche Voreinstellung und sagt das in der
Aufbewahrungsübersicht auch so.

Nach Ablauf schlägt sie einen eigenen Löschstapel vor: freigegeben werden
die **personenbezogenen Zeilen** gelöscht, nachdem ihre **Summe** auf der
Information festgeschrieben wurde. Die Mitteilung und die Quote überleben
die Namen. Liegt für einen Empfänger ein Aufbewahrungsvorbehalt vor, wird
die gesamte Information übersprungen.

## Wer darf senden

- **Administrator** — jeden Empfängerkreis im Unternehmen.
- **Standortadministrator** und **EHS-Fachkraft** — innerhalb ihrer
  Standorte.
- **Führungskraft** — nur die eigenen Organisationseinheiten und die
  Arbeitsplätze darin, Sicherheitswarnung eingeschlossen.
- **Beschäftigte** — nie.

Geprüft wird nicht nur beim Auswählen, sondern noch einmal beim
Veröffentlichen: ein Entwurf kann älter sein als eine inzwischen entzogene
Zuständigkeit.

## Häufige Fragen

**Kann ich eine veröffentlichte Information korrigieren?**
Archivieren und neu senden. Die alte bleibt mit ihrem Nachweis erhalten.

**Was ist der Unterschied zur Unterweisung?**
Eine Sicherheitsinformation ist eine Mitteilung mit Kenntnisnahme. Eine
Unterweisung ist eine gesetzlich geforderte Schulung mit Gültigkeitsdauer.
Für eine Pflichtlektüre mit Lesebestätigung nutzen Sie die Unterweisung,
nicht die Sicherheitsinformation.
